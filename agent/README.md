# Agent Process Rules

Loop Engineeringのagent/process documentationです。

- `WORK-TRACKING.md`: Map / Decision / Spec / Task lifecycle、repository knowledge promotion、handoff
- `PARALLEL-WORK.md`: 複数chat / agent / human workerによる並列実装の競合検知・reservation・merge safetyの正本
- `PARALLEL-WORK-CHECKLIST.md`: `PARALLEL-WORK.md` の実行時短縮チェック

横断的な必須ルールはrepository rootの `AGENTS.md` から参照されます。
